# 『はじめてのコーヒー教科書』理解確認ワークブック

このワークブックは、用語を当てるためではなく、本文の知識を説明・比較・判断・応用できるか確かめるためのものです。先に問題へ答え、次に「解答と考え方」と照合してください。表現が模範解答と同じでなくても、根拠と条件が説明できていれば正解です。

## 第1章　コーヒーは果実の種である

### 問題

1. コーヒーチェリー、生豆、焙煎豆の関係を、工程の順に説明してください。
2. 「アラビカ／ブルボン／ナチュラル」を、種・品種・精製へ分類してください。
3. 袋に「ピーベリー」とあるとき、何が分かり、何は分かりませんか。
4. 同じブルボンでも味が異なる理由を三つ挙げてください。

### 解答と考え方

1. チェリーは果実、生豆は果肉などを除いて乾燥した未焙煎の種、焙煎豆はそれを加熱したものです。
2. アラビカは種、ブルボンは品種、ナチュラルは収穫後の精製です。異なる種類の情報を分けて読めることが要点です。
3. 通常二つ育つ種のうち一つだけが発達した丸い形状だと分かります。品種、産地、品質、味はそれだけでは決まりません。
4. 例は生育環境、熟度、精製、焙煎、抽出です。三つ以上を因果関係とともに説明できれば十分です。

## 第2章　味を「好き嫌い」と「観察」に分ける

### 問題

1. 「おいしい」だけでは次の豆選びに使いにくいのはなぜですか。
2. 「軽やか」と「薄い」はどのように異なりますか。
3. 熱いときだけで評価せず、冷める途中も観察する理由を説明してください。
4. 「酸っぱい」を、種類・強さ・質が伝わる記録へ書き換えてください。

### 解答と考え方

1. 好みの結論であり、香り、酸、甘さ、質感、後味のどこを次回変えたいか特定できないからです。
2. 軽やかは質感の特徴になり得ます。薄いは主に液体の濃度が低い状態を示します。
3. 温度で香りの立ち方や味の感じ方が変わり、温かい・冷めた状態で酸、甘さ、後味を識別しやすくなることがあるためです。
4. 例は「柑橘を思わせる酸が中程度で、明るく短く残る」です。果物名は同じ味が含まれるという意味ではなく、連想語として使います。

## 第3章　産地は国名ではなく生育環境として読む

### 問題

1. 高標高を品質点数のように扱えない理由を説明してください。
2. 同じ標高の二農園でも気温や成熟が異なり得る条件を二つ挙げてください。
3. 「火山性土壌だから火山の味がする」という説明の問題点は何ですか。
4. 産地表示を国名からどの順に詳しく読むとよいですか。

### 解答と考え方

1. 標高は気温などを考える手掛かりであり、緯度、日照、品種、樹の健康、収穫熟度なども品質へ関わるからです。
2. 緯度、斜面の向き、海からの距離、雲、風、日照などから二つ挙げます。
3. 土壌は根の発達や水・養分の利用に関係しますが、土壌物質の味がそのままカップへ移るわけではありません。
4. 国、地域、農園や精製所、標高、品種、精製、収穫期を重ねて読みます。

## 第4章　収穫と精製を工程として理解する

### 問題

1. 三つの主要精製を、乾燥時に種の周囲へ何を残すかで比較してください。
2. 「発酵はウォッシュドだけで起こる」はなぜ誤りですか。
3. 乾燥の最終水分だけでなく、速度と均一性も重要なのはなぜですか。
4. 精製差を確かめる飲み比べで、そろえるべき条件を挙げてください。

### 解答と考え方

1. ウォッシュドは粘液質を除きパーチメントで、ナチュラルは果実のまま、ハニーは果皮を除き粘液質を残して乾燥します。
2. 果実や粘液質には微生物と酵素が関わるため、ナチュラルやハニーでも発酵は進みます。
3. 停滞や乾燥むらは、カビ、好ましくない発酵、保存中の劣化につながるためです。
4. 同一または近い農園・地域、同じ品種、近い焙煎度と抽出条件をそろえ、そろわない条件も記録します。

## 第5章　焙煎は素材を加熱して香味を形成する

### 問題

1. 焙煎中に豆の構造と香りはどう変化しますか。
2. 浅煎り・中煎り・深煎りに世界共通の境界がないことは、購入時に何を意味しますか。
3. 深煎りが一般に抽出されやすい理由を説明してください。
4. 同じ生豆の浅煎りと深煎りを比べるとき、何を観察しますか。

### 解答と考え方

1. 水分が減り、膨らんで多孔質でもろくなり、糖やアミノ酸などが関わる褐変反応で色と香りが形成されます。
2. 焙煎度名だけで決めず、豆の色、店の説明、実際の味も確認します。
3. 加熱で組織がよりもろくなり、成分が湯へ移りやすくなる傾向があるためです。
4. 素材由来の花・果実、加熱由来の香ばしさ・カカオ・苦味、酸、甘さ、抽出の進み方を観察します。

## 第6章　商品表示を情報の種類ごとに読む

### 問題

1. 「ウイラ／カトゥーラ／ウォッシュド／浅煎り」を四種類の情報へ分けてください。
2. AAやSHBだけで味や品質を確定できない理由は何ですか。
3. フレーバーノートに「桃」とあれば、桃が原材料に含まれるという意味ですか。
4. 再購入しやすくするため、袋から何を記録しますか。

### 解答と考え方

1. ウイラは地域、カトゥーラは品種、ウォッシュドは精製、浅煎りは焙煎度です。
2. 等級の基準は国や制度ごとに異なり、粒の大きさ、標高、欠点などを示す区分で、世界共通の風味点数ではないからです。
3. 通常は香味の連想語であり、香料や原材料の表示ではありません。
4. 国・地域・農園や精製所、ロット、品種、精製、焙煎度、焙煎日、収穫期など、表示された情報を記録します。

## 第7章　まず一杯淹れるための基準レシピ

### 問題

1. 基準レシピが「正解」ではなく「比較の基準」であるとはどういう意味ですか。
2. 粉15 g、湯240 gの粉液比を求めてください。
3. 水を変えた日に、その事実を記録すべき理由は何ですか。
4. 同じ数値でも味が再現しないとき、確認する項目を三つ挙げてください。

### 解答と考え方

1. まず条件を固定して一杯を作り、観察結果を基に一項目だけ変えるための出発点という意味です。
2. 240÷15=16なので1:16です。
3. 水の成分やにおいは抽出と味へ影響し、豆やレシピ変更との区別が必要だからです。
4. 例は計量、挽き目と粒度分布、注湯量・流量、蒸らしの濡れ方、予熱、豆の鮮度です。

## 第8章　産地情報を読むための共通原則

### 問題

1. 産地を「味の答え」ではなく「住所」と捉える利点は何ですか。
2. 地域差を比べたいとき、近づけるべき条件は何ですか。
3. 「在来系統」「カティモール」の表記で追加確認が必要なのはなぜですか。
4. 条件を完全に一致させられない比較にも学習価値を持たせるにはどうしますか。

### 解答と考え方

1. 国名で味を固定せず、地域、環境、品種、精製など原因候補を調べられます。
2. 焙煎度、精製、抽出条件をできるだけ近づけます。
3. 単一品種でなく広い系統群を指すことがあり、その内部に異なる遺伝的背景や特性が含まれ得るためです。
4. 一致しない条件を明記し、感じた差を一つの要因だけへ断定しません。

## 第9章　中南米の産地

### 問題

1. 明るい果実方向と香ばしい甘さ方向のブラジル豆を比べるなら、表示の何を確認しますか。
2. コロンビアのウイラ、ナリーニョ、サンタンデールを同じ特徴で扱えない理由は何ですか。
3. 「パナマ・ゲシャ」だけで高品質と判断できない理由を説明してください。
4. 中南米の豆を二つ選ぶ比較計画を、目的と固定条件を含めて作ってください。

### 解答と考え方

1. 地域、精製、品種、焙煎度を確認します。特にナチュラルかパルプドナチュラルかは重要な比較軸です。
2. 南北に広いアンデス沿いで環境や収穫期が異なり、地域内でも品種や精製が異なるためです。
3. 品種は可能性の一要因で、農園、区画、栽培、熟度、精製、焙煎も品質と味へ関わるからです。
4. 例は「グアテマラ二地域の違いを見るため、どちらもウォッシュド・近い焙煎度で同じレシピにする」です。

## 第10章　アフリカとイエメンの産地

### 問題

1. エチオピア豆で地域と精製を組み合わせて読む必要があるのはなぜですか。
2. ケニアのAAから分かることと、分からないことを分けてください。
3. ルワンダやブルンジで農園名がなくても、由来を読む手掛かりは何ですか。
4. イエメンの「モカ」を、品種名やチョコレート味と即断できない理由を説明してください。

### 解答と考え方

1. 産地内に多様な系統と環境があり、ウォッシュドとナチュラルでも工程と見られやすい香味が異なるためです。
2. 主に豆の大きさの区分が分かります。官能品質、地域、品種、精製の良否はAAだけでは確定しません。
3. 地域、ウォッシングステーションまたはファクトリー、精製、ロット、収穫期です。
4. モカは港名に由来する歴史的呼称として使われてきたため、文脈を確認する必要があります。

## 第11章　アジア・太平洋の産地

### 問題

1. インドネシア産をすべてスマトラ式とみなせない理由は何ですか。
2. ベトナム豆を選ぶとき、最初に種を確認する理由を説明してください。
3. インドのモンスーン加工は、産地・品種・工程のどれですか。どのような処理ですか。
4. パプアニューギニア豆の由来を詳しく読む項目を挙げてください。

### 解答と考え方

1. 多数の島と地域があり、ジャワやバリを含めウォッシュドなど別の精製も行われるからです。
2. 国内生産の中心はカネフォラですが、高地ではアラビカもあり、味と用途を考える前提が大きく異なるためです。
3. 工程です。生豆を湿った季節風へさらす加工を指します。
4. 州、農園または精製所、共同処理か独立農園か、品種・系統、精製、焙煎度を確認します。

## 第12章　産地知識を購入と比較へ使う

### 問題

1. 袋から味を予想するとき、「仮説」に含めるべき二要素は何ですか。
2. 味から産地を一つに当てることを目的にしないのはなぜですか。
3. 「フルーティーな豆が欲しい」を、店員が比較しやすい条件へ書き換えてください。
4. 前回の豆から「酸を少し穏やかに、甘さを増やしたい」とき、何を持って相談しますか。

### 解答と考え方

1. 表示に基づく根拠と、実際に確かめる観察項目です。
2. 似た香味は複数の産地・品種・工程から生じ、焙煎と抽出にも左右されるためです。
3. 例は「熟したベリー系の香り、丸い酸、重すぎない質感。ブラック用」です。
4. 前回の商品名・表示、焙煎度、淹れ方、感じた酸・甘さ・質感・後味を伝えます。

## 第13章　濃度と抽出度を分ける

### 問題

1. 濃度と抽出度を、それぞれ何を基準にした尺度か説明してください。
2. 薄いのに抽出が進んでいる一杯は起こり得ますか。理由も述べてください。
3. 少ない湯で濃く作っても抽出不足になり得るのはなぜですか。
4. 家庭で「抽出不足」と断定せず候補として扱うべき理由は何ですか。

### 解答と考え方

1. 濃度は飲み物に溶けた成分の濃さ、抽出度は使用した粉から液体へ移った成分の割合です。
2. 起こり得ます。多い湯で成分を十分取り出しても、出来上がった液体では希釈される場合があります。
3. 湯量が少なく接触も短ければ、液体は濃くても粉から取り出した割合は低いことがあるためです。
4. 測定器がなければ味と記録からの推定であり、不均一な抽出など複数原因が同じ症状を作るからです。

## 第14章　粉と湯の比率を設計する

### 問題

1. 粉18 gで1:16にする総注湯量を求めてください。
2. 同じ粉量で1:16から1:15へ変えると、主に何がどう動きますか。
3. 湯量変更が濃度だけでなく抽出度にも影響し得るのはなぜですか。
4. 出来上がり量を増やすため粉と湯を同率で増やしても、味が完全には同じにならない理由を説明してください。

### 解答と考え方

1. 18×16=288 gです。
2. 湯が相対的に減り、液体は濃い方向へ動きやすくなります。
3. 粉を通る水量と接触条件も変わるからです。
4. 粉層が厚くなって抵抗、流れ、接触時間、注湯の届き方が変わり得るためです。

## 第15章　挽き目と粒度分布を理解する

### 問題

1. 細挽きが一般に抽出と流れへ与える二つの影響を説明してください。
2. 微粉が味と時間の両方へ影響する仕組みは何ですか。
3. 大きな粒が抽出不足になりやすい場合があるのはなぜですか。
4. 同じ目盛りで結果が安定しないときの確認手順を作ってください。

### 解答と考え方

1. 表面積が増えて抽出が進みやすくなり、粉層の抵抗が増えて流れが遅くなりやすくなります。
2. 速く抽出される一方、フィルターや粒の隙間を塞ぎ、流れを遅くすることがあります。
3. 粒の中心まで湯が届きにくい場合があるためです。
4. 同じ豆を複数回挽き、粉の見え方、時間、味のばらつきを記録し、清掃、刃、投入方法も確認します。

## 第16章　湯温と時間を原因・結果の両面から見る

### 問題

1. 湯温を「苦味のつまみ」とだけ考えると何を見落としますか。
2. 87〜93 ℃の研究例から、家庭の調整について何が言えますか。
3. 抽出時間が30秒長くなったとき、時間そのもの以外に調べる項目を挙げてください。
4. 湯温の影響だけを比較する実験を設計してください。

### 解答と考え方

1. 温度は多くの成分が溶ける速度を変え、挽き目、時間、攪拌との組み合わせで結果が決まる点を見落とします。
2. 濃度と抽出度が同程度なら温度そのものの官能差が小さい例があり、温度だけで味を断定できないと言えます。
3. 挽き目、微粉、粉量、注湯、ドリッパー、フィルター、詰まりを調べます。
4. 同じ豆・粉量・湯量・挽き目・注湯を保ち、湯温だけを約2 ℃変え、時間と味を記録します。

## 第17章　注湯と蒸らしで粉層を整える

### 問題

1. 注湯を「何回に分けたか」だけで説明できない理由は何ですか。
2. 蒸らしの二つの目的を説明してください。
3. 蒸らし後に乾いた粉が残る場合、待ち時間だけを延ばしても解決しないのはなぜですか。
4. 注湯を再現するために記録する数値を挙げてください。

### 解答と考え方

1. 各投の湯量、流量、高さ、位置、間隔も粉層の濡れ方と流れへ影響するためです。
2. 粉全体を濡らし、残るガスを逃がして、本抽出の湯が偏りにくい状態を作ることです。
3. 湯が触れていない場所は、時間を延ばしても新たには濡れないためです。湯量や位置を見直します。
4. 各投の開始・終了時刻、湯量、総注湯量、落ち切り時間を記録します。

## 第18章　器具とフィルターの違いを流れとして捉える

### 問題

1. 円すい型という名称だけで流速や味を決められない理由は何ですか。
2. 紙と金属フィルターで、液体へ通りやすいものの違いを説明してください。
3. 金属フィルターが紙より上位または下位とは言えないのはなぜですか。
4. 二つのドリッパーを公平に比較する計画を作ってください。

### 解答と考え方

1. 穴、リブ、底面、紙の密着、粉層、注ぎ方の組み合わせで流れが決まるからです。
2. 金属は油分と微粒子を通しやすく、紙はそれらを保持しやすい傾向があります。
3. 欲しい質感、手入れ、再現性という目的によって適否が変わるからです。
4. 豆、粉量、湯量、湯温、初期の挽き目を近づけ、流れと味を記録し、その後各器具に合う挽き目も検証します。

## 第19章　味を診断して次の一手を選ぶ

### 問題

1. 「薄く、酸が突出し、甘さが乏しい」一杯で考える二つの課題は何ですか。
2. 濃さはよいが乾いた渋さがあるとき、抽出過多以外に何を疑いますか。
3. 深煎りの苦味と抽出由来の苦味を切り分けるには何を確認しますか。
4. 味が毎回変わる場合、レシピ調整より先に何をしますか。

### 解答と考え方

1. 低濃度と抽出不足の可能性を分け、どちらを先に検証するか決めます。
2. 不均一な抽出、微粉の詰まり、過度な攪拌、偏流を疑います。
3. 焙煎度と豆の説明を確認し、微粉、時間、攪拌を一項目ずつ比較します。
4. 計量、粒度、流量、蒸らし、予熱など、同じ条件を再現できているか確認します。

## 第20章　自分のレシピを作る

### 問題

1. 「おいしい一杯」を、観察可能な目標へ書き換えてください。
2. 一度に一変数だけ変える理由を説明してください。
3. 一度だけ良かった条件を基準レシピにしないのはなぜですか。
4. 「濃さはよいが酸が鋭く甘さが弱い」一杯の次回計画を、固定条件と変更条件に分けて書いてください。

### 解答と考え方

1. 例は「柑橘の香り、明るいが鋭すぎない酸、軽い質感、甘い後味」です。
2. 味の変化と操作の因果関係を判断できるようにするためです。
3. 注湯や粒度の偶然で得た結果かもしれず、同条件で近い結果が出る再現性の確認が必要だからです。
4. 粉量、湯量、比率、湯温、注湯、器具を固定し、挽き目だけを少し細かくする例が考えられます。結果を同じ四項目で記録します。
